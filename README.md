# 🌸 Mother’s Day Website - A Gift for Mom ❤️

A heartfelt **Mother’s Day web experience** built with **HTML, CSS, and JavaScript** to celebrate moms through memories, emotions, and love.

This project is designed as an emotional interactive website where a mother can:

❤️ Read a heartfelt Mother’s Day message  
💌 Ask emotional questions she may want to ask her son  
🌷 Experience warm animations and transitions  
📷 Upload a favorite memory photo  
🎁 Receive an emotional poem and certificate

---

## ✨ Features

### 🌸 Opening Experience
- Elegant flower bloom animation
- Mother holding child visual theme
- Soft pastel UI with floating petals
- Personalized **From / To** fields
- Beautiful intro transitions

### ❤️ Mom Q&A Experience
Interactive emotional question cards like:

- *Did I scold you too much?*
- *Have I loved you enough?*
- *Am I a good mother?*
- *Did I make mistakes?*
- *Will you always remember me?*

Each question opens a heartfelt answer in a chatbot-style interaction.

### 🥹 Emotional Poem Page
A warm poem dedicated to moms with:

- Smooth text animations
- Elegant typography
- Memory upload section
- Drag & Drop image support
- Floating hearts animation

### 🏆 Mother Certificate
A beautiful downloadable certificate:

**“Best Mother in the Entire World ❤️”**

Includes:
- Personalized photo frame
- Elegant floral design
- Downloadable keepsake

## 🚀 How to Run

### Method 1: Open directly
Simply open:

```txt
index.html
```

in your browser.

### Method 2: Run locally

Clone the repository:

```bash
git clone https://github.com/Jivesg-Bhandari-lab/mothers-day-website.git
```

Go to project folder:

```bash
cd mothers-day-website
```

Open `index.html` in browser.
